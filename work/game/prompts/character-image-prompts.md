# Character image prompts (for ChatGPT image generation, then Tripo)

These prompts cover the test scene cast from Chapters 1 and 2. Details come from `work/game/character-sheet.md`.

## How to use
1. Open a new ChatGPT chat for each character.
2. Upload `work/redesign/art/visual-bible.png` first. Do this in every chat.
3. Paste the character prompt. It already contains the shared 3D rules.
4. When the front view looks right, ask in the same chat: **"Now the exact same character from the back, same pose, same lighting, same background."**
5. Save the images as `work/game/refs/<name>-front.png` and `<name>-back.png`.
6. Send them to me. I'll check them against the character sheet before we spend any Tripo credits.

## What to reject
- Hands that hold something, or that are fused to the body or clothing
- Feet cut off at the edge of the frame
- Strong shadows, rim light or a coloured background
- A second figure, text or a frame
- For the Iwang: a closed chest, eyes, or a mouth
