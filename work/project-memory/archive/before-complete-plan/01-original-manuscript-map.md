# ORIGINAL MANUSCRIPT MAP

Sumber tunggal aktif: Schlelberg - Draft 3 (1).docx. Diperbarui 28 September 2026. Seluruh naskah dibaca: sekitar 11.079 kata, prolog dan 13 bab, 343 paragraf tidak kosong. Dokumen sumber tidak diubah. Nomor paragraf merujuk urutan paragraf Word, bukan nomor halaman.

FAKTA = dinyatakan/diperlihatkan naskah; TAFSIR = pembacaan editorial; USUL = belum menjadi kanon; TERBUKA = belum dijelaskan. Pernyataan tokoh tidak otomatis merupakan fakta dunia.

## Struktur faktual

Panggilan → perpisahan → ultimatum pengorbanan → kekalahan/sandera → pelatihan dan godaan → pilihan kekuatan merusak → kematian mentor → kembali dan menghimpun rekan → mengalahkan Sus → ekspansi kelompok Toby.

Naskah mempunyai akhir alur melawan Sus, tetapi penutupan Schlelberg, asal pesan, hubungan Maria, dan hukum pengorbanan belum tuntas. Bukan naskah yang hanya berisi pembukaan.
